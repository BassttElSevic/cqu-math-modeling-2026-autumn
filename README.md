# 2026 重庆大学数学建模秋季赛资料

本仓库保存当前美赛工作目录的可分发压缩包，以及关于埃博拉传播模型的交互式可视化。

## 完整资料包

[下载完整项目压缩包](release/cqu-math-modeling-2026-autumn-full.zip)

压缩包包含：

- 竞赛题目、原始数据与 PDF 资料。
- `output/` 中的 LaTeX 源码、图表和生成 PDF。
- `work/` 中的翻译、排版与模型工作文件。
- 根目录中的论文与参考 PDF。

为控制仓库体积，压缩包排除了本地 Git 数据、字体缓存、临时目录、LaTeX 运行时缓存、发布目录自身，以及与解压题目目录重复的原始 RAR。
